# Literature Search and Management System

Standalone repository for academic literature search, PDF management, reference tracking, and LLM-powered paper summarization.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17954157.svg)](https://doi.org/10.5281/zenodo.17954157)

The toolkit searches scholarly metadata, maintains a JSON library index and
BibTeX bibliography, and supports optional PDF retrieval, extraction,
summarization, and exploratory analysis.

Start with the [documentation index](docs/README.md) for setup and workflows.
The [offline reproduction guide](docs/reproduction.md) exercises indexing and
export on synthetic records, then renders the [software methods manuscript](docs/manuscript/README.md).
