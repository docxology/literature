# Abstract

The Literature toolkit stores scholarly metadata in a local JSON index and
emits a companion BibTeX bibliography. This methods note describes how shared
citation keys connect these representations. A synthetic replay checks
duplicate-key reuse, JSON reload, and agreement with the emitted BibTeX
entries. The observations establish behavior for the fixture under the
exercised software version. They do not measure provider coverage, retrieval
quality, or systematic-review completeness.
