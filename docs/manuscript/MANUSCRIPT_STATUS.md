# Manuscript Status

- **Repo type:** Tool / library — standalone literature search, PDF management,
  reference tracking, and LLM summarization system (Zenodo software release,
  DOI 10.5281/zenodo.17954157 per root `README.md` badge).
- **Why no publication-target manuscript applies today:** evidence checked —
  the repo ships a tool (`infrastructure/` layers, `scripts/`, `tests/`) with
  tool documentation under `docs/` (guides, module docs, API/CLI reference).
  The `data/output/` directory holds clustering outputs of its own library
  usage, but there is no research README framing findings, no figures-of-record
  registry, and no claims ledger; the repo self-describes as a system, not a study.
- **What would trigger creating a `manuscript/`:** publishing an original
  research result derived from using the system (e.g. a meta-analysis corpus
  study), with analysis outputs and figures of record to source claims from.
