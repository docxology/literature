metadata replay, and its limits. `config.yaml`, `preamble.md`, and
`references.bib` configure the local PDF and web build.

are separate from the repository's tracked corpus and bibliography.
Use the [offline reproduction guide](../reproduction.md) to regenerate the
figure, inspect the evidence, and render with pinned Template.
